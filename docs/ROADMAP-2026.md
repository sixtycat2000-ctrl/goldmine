## 1. 已经赢下的（按证据说话）

**对 DigUp：**
1. **事故继承基本完成，且超越**。P0 守卫（中途拔盘≠全删、参考向量测试）、
   P2 运维面（iCloud dataless 拦截、断管纪律、查询期删文件过滤、estimate、
   音频尾窗门、阿拉伯丢字页 OCR 替换）已落地；多模态完整上线
   （1412 行 C 边车 + 逐位一致缩放），DigUp 的 GUI 层产物按「CLI 不适用」明确不采。
2. **开放性**。DigUp 仓库只有单个 squash commit、git 史不可用；goldmine 是
   MIT、全证据链入库（台账/五讲/锚点卡/逐提交档案）。
3. **服役面**。DigUp 只有 GUI；goldmine 有 CLI + MCP 四只读工具 + serve + watch。
4. **评测纪律本身是护城河**。3,200+ 离线测试、420 题冻结套件、预注册 +
   对抗评审、三态结论——DigUp 的 A/B 数字散落在源码注释里，没有可复跑的框架。

**对 QMD（native 视图，210 题）：**
5. **多媒体原生覆盖**：Goldmine s@5 **78.3%** vs QMD 最强臂 66.1%；QMD 原生
   只读 4 种文本格式，62/122 份文件它根本看不见。
6. **速度**：中位 1.4s vs 21.8s（约 15×）；p95 1.7s vs 36.5s。
7. **第一名命中**（common 视图 s@1）：82.2% vs 80.6%。
8. **抗噪声诚实**：空答率 43–60% vs QMD query **0%**（30 条捣乱查询全给结果）。

## 3. 未来必须赢的五个战场（按顺序）

### 战场 1 · 红门打绿（一切的前提）
12 项质量门转绿之前，任何对外主张都只能是「能力覆盖」叙事，不能是「质量」
叙事。手段已就位：交叉编码器窗口仲裁（已落地）、准入再校准（必须 A/B +
train/holdout 一致）、噪声题扩容（R10c）。**判据**：current00N 一轮 dev 跑分
12 门全绿，holdout 一次确认。

### 战场 2 · 纯文本精搜追平 QMD
QMD 赢我们的唯一硬指标是 common 视图 s@5。追平它 = 在「别人 preprocessing
好」的最坏假设下也不输。手段：交叉编码器向上臂（不只仲裁窗口，参与排序）、
CJK 分词补腿（二元切分/trigram 择一，A/B 定）、R3 多跳拆题。**判据**：common
视图复测 s@5 ≥ 98%，native 优势保持。

### 战场 3 · 「材料→答案」端到端闭环
找到 ≠ 答对。把 480 答题 + 960 判卷作业跑完，让 PACK 的 90.6% 盲评成为
常测指标而非历史快照。这是对 Spotlight/grep 无法参战的维度——他们不产材料包。
**判据**：answer_baseline.json 常态化 --gate 绿；判卷一致性 ≥ 0.9。

### 战场 4 · 服役面可靠性（serve/watch/MCP）
本地搜索的日用体验战场：亚秒检索的常驻纪律、断电续跑、真实 iCloud/病态
PDF 路径补证（当前 MISSING）。**判据**：十分钟受控 watch 实测 + 装轮 smoke
全绿；MCP 装轮证明落档。

### 战场 5 · 决策层 R11（差异化终局）
查询路由、校准弃答、判卷、关系核实、拆题——「不确定就说不确定」的产品化。
这是 QMD 完全没有的维度：它对噪声查询 0% 空答，正是没有弃答能力的表现。
**判据**：spec §4 验收表（arguana nDCG@10 ≥ 0.56、trap 拒答率不降、判卷
一致性 ≥ 0.9）。

## 4. 对 DigUp 的持续姿态

DigUp 教训挖掘转入**常态低频**：结构性改动前复查 §4 残余表；新模态/新段型
落地时重审 A6/A7/静默窗三件；estimate 校准在战场 4 顺手做（真跑一天 watch
取速率替换先验）。挖掘的方法论本身（只读代理 + file:line 出处 + 防御规则）
保留为模板。

## 5. 永远不做（沿用铁律）

不聊机器人、一切本地无云、不扫全盘、不自动更新、不埋点、无账号、
holdout 只在审计门下开。**营销语言与证据同等纪律：没打绿的门不以完成时
写进官网。**
