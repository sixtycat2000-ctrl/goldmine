ANSWER:
The RetrieveContext request (RetrieveRequest) carries: a `Query` message with fields `text_query` (string), `audio_query` (bytes), and `query` (string), plus `max_results` (int32), `min_similarity_score` (double), `user_id` (string), and repeated `allowed_document_ids` [3]. The text query and audio query are mutually exclusive; if neither is provided the call fails with INVALID "Neither text query nor audio query was provided", and if the model pipeline is not loaded it fails with UNAVAILABLE "Pipeline not initialized" [2]. When `allowed_document_ids` is empty the request goes through the unfiltered retrieval pipeline, otherwise it is invoked with the document-ID filters applied [1]. The response (RetrieveResponse) returns a `chunks` list of RetrievedChunk messages [3]. Each chunk has four fields: `text` (string), `relevance_score` (double), `document_id` (string), and `mime_type` (string) [3]. Results are ordered by similarity descending, and an empty pipeline result yields a normal empty list [2].
