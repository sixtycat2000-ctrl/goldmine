QUESTION: how are audio transcript chunks positioned in time and made seekable in citations

(no extra note for this question)

CHECKS:
1. Audio transcript segments carry loc in seconds (kind=audio)
2. Citations render seekable time ranges like 12:07-18:45 in markdown/pack output while JSON keeps raw seconds
3. Within a distill card, many chunks from one audio file can collapse to a single citation spanning min(loc)..max(loc_end) (the episode effect)

ANSWER:
Audio transcript chunks are positioned in time by a `loc` field measured in seconds (with an end position), plus `kind='audio'`, and `_fmt_loc` renders this range as e.g. `12s-35s` [1]. When more than 3 chunks in a card share one audio file, citations collapse to a single citation per file spanning `min(loc)..max(loc_end)`, so an "episode mention" reads as one entry instead of many [1]. For human-readable output, audio/video locations render as `12:07–18:45` in markdown/pack, while raw seconds are kept in JSON [1]. This human time format makes each citation seekable in any player [1].
