QUESTION: what journal mode does the goldmine sqlite index use

2. WAL is the deliberate, kept-by-decision default policy: one-shot commands rely on SQLite's own crash recovery, and ingest ends with a TRUNCATE checkpoint so backups stay single-file

ANSWER:
The goldmine SQLite index uses WAL (write-ahead logging) journal mode [1]. Each index is a single SQLite file opened with `PRAGMA journal_mode = WAL`, alongside `foreign_keys ON` and `busy_timeout 60000` [1]. The v2 design explicitly decided to keep WAL as the default: one-shot commands need no special handling since SQLite recovers on next open, the daemon runs passive checkpoints when idle, and ingest ends with a TRUNCATE checkpoint so backups are single-file-honest [2].
