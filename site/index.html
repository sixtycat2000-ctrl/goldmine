goldmine 是一个命令行搜索引擎。你指定文件夹，它索引文本、PDF、截图、录音、视频，把内容变成向量后在本地检索。索引是磁盘上的一个 SQLite 文件。

03

工作原理

从磁盘到可搜，四步

01 · SCOPE

你指定文件夹，只索引这些

没有默认全盘扫描。构建产物目录、密钥文件、iCloud 未下载占位一律跳过并留原因——索引不会触发一次 iCloud 下载。

02 · EMBED

内容变向量，每种媒体一条路

文本走钉版 embeddinggemma-2。装上边车后：图像/音频向量、视频关键帧、OCR、whisper 转录（命中跳到那一秒）。

03 · HYBRID SEARCH

含义 + 精确词融合，过程可查

score = 1.0·语义 + 2.0·词覆盖^1.5 + 类型加成；编号查询自动反转。--why 把算术摆出来。

04 · ONE FILE

提交与存储：一文件一事务，一库一文件

每个文件单事务提交；整个索引是一个 .sqlite 文件，备份就是复制它。

quickstart — 零模型也能跑
git clone https://github.com/sixtycat2000-ctrl/goldmine && cd goldmine
python3 -m venv .venv && .venv/bin/python -m pip install .
printf '知识库：退款期限为四十五天。\n' > sample/notes.md
.venv/bin/goldmine ingest sample --db s.sqlite --lexical-only
.venv/bin/goldmine search '退款期限' --db s.sqlite --lexical --pack
04

特点

六个工程决定，多数仓库没有

诚实是接口，不是口号

零命中打印 nothing found 加一步建议；OCR/模型缺失逐文件写原因；换过模型的库直接拒绝服务（exit 3）。降级永远大声。

向量家族不混

模型、提示词、媒体预处理、预算全进一个指纹哈希。指纹一变，搜索拒绝混库。参考向量测试把模型输出钉到逐位。

参数改动要过统计门

阈值与权重全部预注册；改动用统计检验判定，不显著就回滚。曾扫到更好的 3.5 门，一次扫描不足采信——记录在案、不采纳。

证据先于主张

结论只有三态，PASS 必须附原始回执，「基本通过」是禁语。结构改动先预注册再对抗评审。别处测得的收益复测为零，按规则回滚。

媒体管线是偏执的

图片缩放逐位复刻（22 位定点 + 黄金表）；尾窗 ≥2 秒新音频才保留；关键帧去重封顶。保的是向量家族的纯度。

本地优先是代码事实

上传路径不存在：唯一网络请求是显式模型下载与你指定的 URL。MCP 四个只读工具；守护进程全部显式启动。
