快速开始

Python 3.12+，基础包只依赖 numpy。零模型也能用——纯词法检索：

quickstart
python3 -m venv .venv && .venv/bin/python -m pip install .
goldmine init                       # 引导式：环境、模型、文件夹、首次摄取
goldmine ingest ~/notes --db lib.sqlite
goldmine search '退款期限' --db lib.sqlite --pack

启用语义检索：安装钉版模型后再摄取一次。

semantic
goldmine model install embeddinggemma-2-Q8_0
goldmine ingest ~/notes --db lib.sqlite

可选工具：Poppler、ffmpeg + whisper、Vision OCR、goldmine-embed 助手。缺哪个就降级哪个，原因写在能力行里。
