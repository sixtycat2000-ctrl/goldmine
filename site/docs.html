快速开始

macOS 14+、Apple Silicon。独立包自带 Python、钉版搜索引擎、OCR 与 MCP；安装时校验并准备默认模型。

独立包目前为本地候选版本，公开下载待发布。将安装脚本、包与校验文件放在同一目录后运行：

install
sh install.sh
"$HOME/.local/bin/goldmine" init

开发者源码试用

Python 3.12+，基础包只依赖 numpy。零模型也能用——纯词法检索：

quickstart
git clone https://github.com/sixtycat2000-ctrl/goldmine && cd goldmine
python3 -m venv .venv && .venv/bin/python -m pip install .
mkdir -p sample && printf '知识库：退款期限为四十五天。\n' > sample/notes.md
.venv/bin/goldmine ingest sample --db s.sqlite --lexical-only
.venv/bin/goldmine search '退款期限' --db s.sqlite --lexical --pack

源码安装启用语义检索：还需准备兼容 llama-server，再安装钉版模型并重新摄取。

semantic
.venv/bin/goldmine model install embeddinggemma-2-Q8_0
.venv/bin/goldmine ingest ~/notes --db lib.sqlite

可选工具：Poppler、ffmpeg + whisper、Vision OCR、goldmine-embed 助手。缺哪个就降级哪个，原因写在能力行里。
